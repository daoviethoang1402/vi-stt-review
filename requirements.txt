# requirements.txt — pin môi trường chạy khảo sát (conda env `vi-stt`).
#
# Đích: Linux x86_64 · CUDA 12 · Python 3.11 (máy dev) và 3.13 (Kaggle). Đã cài sạch và
# chạy đủ 7 model trên Python 3.13 (2026-11-27). GPU sm_75 (cùng kiến trúc với T4).
#
# Cài:
#   python -m pip install -r requirements.txt
#   python -m pip install --no-deps chunkformer==1.2.2 pyctcdecode==0.5.0 \
#                                     pygtrie==2.6.2 hypothesis==6.170.15
#   python -m pip install --no-deps nvidia-cuda-runtime-cu12==12.9.79
#   python -m pip uninstall -y torchvision      # Kaggle / Colab: see below
#
# Vì sao cài riêng `nvidia-cuda-runtime-cu12==12.9.79`: ONNX Runtime 1.28 nhúng trong
# sherpa-onnx cần symbol `cudaLibraryGetKernel` (CUDA runtime ≥ 12.9). torch 2.6.0+cu124
# khai đúng 12.4.127, nên không pin được trong file này (pip báo xung đột); phải cài đè
# bằng `--no-deps`. Thiếu bước này, sherpa in `undefined symbol: cudaLibraryGetKernel …
# Fallback to cpu` và hai model zipformer lặng lẽ chạy CPU. torch vẫn chạy với 12.9.
#
# Vì sao gỡ `torchvision`: dự án không dùng nó, nhưng `transformers` tự import nó nếu có.
# Image Kaggle cài sẵn một `torchvision` build cho torch của image; sau khi file này cài
# torch 2.6.0 đè lên, hai gói lệch nhau và mọi import `transformers` (convert PhoWhisper,
# adapter Qwen) gãy với `operator torchvision::nms does not exist`.
#
# Vì sao hai lệnh cuối phải tách và phải `--no-deps`:
#   • chunkformer 1.2.2 khai `deepspeed`, `langid`, `tensorboardx`. Cả ba chỉ được
#     import trong chunkformer/utils/train_utils.py (đường huấn luyện); pipeline
#     này chỉ dùng ChunkFormerModel nên không cần, mà deepspeed là sdist phải
#     build — cài theo kiểu thường rất dễ gãy.
#   • pyctcdecode 0.5.0 khai `numpy<2.0.0`, trong khi cả stack (torch 2.6, numba
#     0.68, lhotse 1.33, pandas 3) đòi numpy 2.x. Metadata của nó lỗi thời; đã
#     chạy thật với numpy 2.4.6. Ba dependency thật của nó (pygtrie, numpy,
#     hypothesis) vì vậy phải khai tay ở lệnh trên.
#
# Không pin các wheel con `nvidia-*` khác: torch tự khai phiên bản của chúng. Sau khi cài
# đủ, `pip check` báo đúng các lệch đã biết và vô hại: chunkformer (deepspeed, langid,
# tensorboardx, textgrid — chỉ dùng khi huấn luyện), pyctcdecode/numpy, và
# nvidia-cuda-runtime-cu12 12.9.79 (torch khai 12.4.127).
#
# Index phụ: torch `+cu124` chỉ có trên index của PyTorch; wheel sherpa-onnx có
# CUDA nằm ở trang find-links của k2-fsa (wheel mặc định trên PyPI là **CPU-only**,
# cài nhầm là sherpa lặng lẽ chạy CPU).
--extra-index-url https://download.pytorch.org/whl/cu124
-f https://k2-fsa.github.io/sherpa/onnx/cuda.html
